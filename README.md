# Avion 🛋️
Учебный проект интернет-магазина мебели и декора, разработанный на React и JavaScript.

# 📋 О проекте
Этот репозиторий содержит код учебного проекта Avion — интернет-магазина мебели и декора, разработанного в рамках изучения React и JavaScript.

Проект является демонстрацией навыков и не предназначен для коммерческого использования.

# 🎯 Цели проекта
В рамках этого проекта я практиковал:

⚛️ Разбиение UI на компоненты - Создание переиспользуемых React-компонентов

📊 Подъем состояния и его грамотное управление - Эффективное управление состоянием приложения

📝 Работа с формами и пользовательским вводом - Валидация и обработка пользовательских данных

🛣️ Клиентская маршрутизация с React Router - Навигация между страницами SPA

📱 Создание адаптивного layout на CSS Grid/Flexbox - Адаптивный дизайн для всех устройств

🔗 Имитация взаимодействия с бэкендом - Работа с API, загрузка данных, отправка форм
